# neowiz

Brown Dust 2（棕色尘埃 2）相关工具、资源仓库与约会互动配置的统一入口。

## 仓库索引

| 仓库 | 维护者 | 用途 |
| --- | --- | --- |
| [BD2ModManager](https://github.com/LLsetnow/BD2ModManager) | [LLsetnow](https://github.com/LLsetnow) | Mod 管理、预览与同步工具。 |
| [BD2ModPreview](https://github.com/LLsetnow/BD2ModPreview) | [LLsetnow](https://github.com/LLsetnow) | Spine 动画与 Mod 预览工具。 |
| [BD2Modder](https://github.com/LLsetnow/BD2Modder) | [LLsetnow](https://github.com/LLsetnow) | Windows 上的 Spine Mod 图集编辑器，支持贴图替换与 Mod 导出。 |
| [Brown-Dust-2-Asset](https://github.com/LLsetnow/Brown-Dust-2-Asset/tree/master) | [LLsetnow](https://github.com/LLsetnow)（我的 Fork） | Brown Dust 2 美术素材与约会音频，音频位于 `audio/dating`。 |

各项目的安装方法、使用说明和许可条款，请查看对应仓库。Brown-Dust-2-Asset 条目指向本仓库的 fork；其上游由 [bruhnn](https://github.com/bruhnn) 独立维护。

## 约会互动配置

配置目录：[mods/dating-interaction-configs](mods/dating-interaction-configs/)。

包含 `illust_dating1.json` 至 `illust_dating22.json`，共 22 个 JSON 文件，保留原始文件名、目录结构与内容。

```text
neowiz/
├── README.md
└── mods/
    └── dating-interaction-configs/
        ├── illust_dating1.json
        ├── ...
        └── illust_dating22.json
```

## 获取内容

```bash
git clone https://github.com/LLsetnow/neowiz.git
```

克隆本仓库即可获取上述配置文件。需要相关工具或游戏资源时，请通过仓库索引访问对应项目。
